# การทดสอบอัตโนมัติ (สำหรับ Claude ในแชทถัดไป)

ไฟล์ในโฟลเดอร์นี้ไม่ได้ถูกใช้โดยหน้าเว็บ เป็นสคริปต์ทดสอบที่รันในเครื่องทดสอบของแชทเท่านั้น
ไม่แตะ Supabase จริงและเว็บจริง ไม่มีรายชื่อนักเรียนจริง (ข้อมูลในไฟล์ SQL เป็นชื่อสมมติ รหัสแอดมิน `testpass` ใช้กับฐานข้อมูลทดสอบเท่านั้น)

รันทั้งหมด: `bash tests/run.sh` จากรากของ repo

| ไฟล์ | หน้าที่ |
|---|---|
| `run.sh` | สร้าง Postgres ชั่วคราว รันไฟล์ SQL ของ repo ตามลำดับ ใส่ข้อมูลตัวอย่าง แล้วรันการทดสอบทุกตัว |
| `sql/00-base.sql`, `sql/01-admin-base.sql` | ตารางและฟังก์ชันตั้งต้น (ส่วนที่อยู่ใน `supabase-checkin.sql` ของโปรเจกต์ ไม่อยู่ใน repo) |
| `sql/90-sample-data.sql`, `sql/95-checks.sql` | ข้อมูลตัวอย่าง และการตรวจคะแนนรายสัปดาห์ คะแนนของฉัน ตารางการเข้าร่วม การส่งผล Calcu |
| `rpcserver.js`, `stub.js` | ตัวแทน Supabase: หน้าเว็บเรียก RPC แล้วไปรันบน Postgres ทดสอบ ส่วน Realtime ไม่มี เกมจึงใช้ BroadcastChannel (แท็บในเบราว์เซอร์เดียวกัน) |
| `browser/site-pages.js` | การ์ดสัปดาห์ 4, กล่องเช็กชื่อใน /games/, หน้าคะแนนของฉัน, ตารางการเข้าร่วม + CSV, QR ล็อบบี้ Mathmory |
| `browser/calcu-submit.js` | Calcu: เลขประจำตัว, เครื่องใหม่แทนเครื่องเก่า, อันดับที่ส่งเข้าระบบ, ส่งผล |
| `browser/calcu-round.js` | Calcu ห้องจอใหญ่ครบหนึ่งรอบ พร้อมสไลด์และ animation |
| `browser/calcu-head.js` | Calcu ห้องเล่นกับเพื่อน, Sudden Death เปิดฉาก, ลดการเคลื่อนไหว |

ภาพหน้าจอจาก `calcu-round.js` อยู่ที่ `/tmp` (เปลี่ยนได้ด้วยตัวแปร `SHOTS`)
